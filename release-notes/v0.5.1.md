## Linux desktop interface

- Manage link cleaning, optional app previews and excluded websites in a Qt desktop window.
- Detect the destination app’s Linux identifier, review it and add it to preview choices.
- Start or stop the background service and inspect Wayland diagnostics from the interface.
- Settings are saved safely; unreadable files and concurrent edits are preserved.

Install the Linux archive from a terminal in your Wayland session. The window requires Qt 6 Widgets and a Qt Wayland plugin. Integrated Linux updates follow in the next delivery; Mac and Windows update feeds remain included.
