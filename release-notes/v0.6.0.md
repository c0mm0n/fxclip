## Linux updates from the desktop window

- Check for Updates in the Qt tray menu and Settings, with release notes, download progress and cancellation.
- Optional daily checks are off by default and run only while the interface is open. Downloads and installation each require confirmation.
- Verify the Linux archive against GitHub's SHA-256 digest before preparing it. Install and Restart replaces the interface and service while preserving settings and login startup.
- Keep the previous files during installation and restore them if installation or relaunch fails. Opening fxclip again activates its existing window instead of starting a second interface.
- Link cleaning stays local. Only authorized updates contact GitHub; the cleaning service never makes network requests.

Install this Linux download manually once to get the updater. macOS and Windows updates continue through their existing in-app flows.
