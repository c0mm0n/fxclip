## Windows updates

- Check for Updates is available in Settings and the tray menu.
- Download a verified update, then choose Restart to Update when ready.
- Automatic daily checks are optional and off by default.
- A per-user installer is now available alongside the portable ZIP. Install this version manually once to enable future in-app updates; settings and counters are preserved.
- Link cleaning stays local. Only authorized update checks and downloads contact GitHub.

macOS signed updates remain available in every release.
