## What's New in fxclip 0.2.0

- 🪟 **fxclip for Windows**: a tray app with the same settings window, previews in the apps you pick, rewritten links kept out of Win+V history
- 🐧 **fxclip for Linux**: a Wayland background service for Sway, Hyprland and KDE Plasma
- 🧪 One set of test links for all three platforms, so every version cleans links exactly the same way
- 🎨 New app icon
- 🛠️ The settings window opens with nothing pre-selected
