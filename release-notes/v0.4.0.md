## What's New in fxclip 0.4.0

- **Updates inside the Mac app**: use **Check for Updates…** from the application menu, menu bar or **Settings › Updates**.
- **Download, install and relaunch** without replacing the app by hand. Every download and installation requires confirmation.
- **Optional daily checks** are off by default. Link cleaning stays offline; only update requests contact GitHub, and copied links are never sent.
- **Signed updates**: Mac update archives and their feed are verified with a dedicated Ed25519 key. The app remains ad-hoc signed, without an Apple certificate bearing a personal identity.

Install this version manually once to get the updater. Windows, Linux and Android still use manual downloads in this release; their integrated updaters follow separately.
