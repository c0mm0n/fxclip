## Android updates from the settings screen

- Open Updates from the settings toolbar, check GitHub and read the release notes. Confirm the download, then choose Install Update.
- Automatic checks are off by default. When enabled, they run at most once a day when the app opens. Cleaning, settings, counters and history stay local.
- Verify the APK's SHA-256, package, newer version code, Android compatibility and signing certificate before opening Android's installer. Invalid files leave the installed app and its data untouched.
- Cancel a download or installation, retry later, or keep a verified download across reopening. Android handles the install-source permission and asks before installing. No silent installation or automatic relaunch is requested.
- Published APKs keep the existing signing key and update in place. Install this APK manually once if the installed version has no updater.

Mac, Windows and Linux updates continue through their existing in-app flows. All update feeds and downloads remain together in GitHub Releases.
